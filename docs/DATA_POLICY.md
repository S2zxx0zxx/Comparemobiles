# Data Policy V1

1. Primary manufacturer sources are preferred for specifications.
2. Region is mandatory. China, India, EU and global variants are not silently merged.
3. Every important value carries provenance: source URL, source type, region, verification date and confidence.
4. Unknown is a valid state. Unknown values must not be converted to zero, false or an invented default.
5. Third-party ratings, reviews, prose and proprietary scores are not copied from comparison websites.
6. Retail prices need a source and checked-at timestamp before they are described as current/live.
7. Product media is stored only when reuse rights are clear; random Google Images are not a media source.
8. Preview data in `src/data/verified-preview.ts` is development/UX seed data from primary pages, not the full production catalog.
